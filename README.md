# MK Toasty — Demo

A minimal Unity demo scene for the [MK Toasty](https://github.com/kirillrybin/com.kiriyo.mktoasty) package.

## Opening the project

1. Clone this branch:
   ```
   git clone -b upm-demo https://github.com/kirillrybin/com.kiriyo.mktoasty.git
   ```
2. Open the cloned folder in Unity 2021.3+
3. Open `Assets/Scenes/MkToastyDemo.unity`
4. Press Play

## Triggering the effect

| Action | Result |
|---|---|
| `Ctrl + T` | Show the toasty silhouette |
| Wait | Appears randomly every 30–120 seconds |

## Requirements

- Unity 2021.3+
- Input System 1.7+
